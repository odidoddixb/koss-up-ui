# 팀 코드 보존 및 통합 변경 범위

## 2번
업체 데이터와 계약 생성 규칙은 원본을 유지합니다. 공통 세션으로 결과 전달, 중복 반영 방지, 조사·계약 상태 저장, 공통 날짜 사용, Base64 이미지 분리만 연동을 위해 적용했습니다. 사용자가 요청한 판정 화면의 내부 코드 제거와 상태바 중앙 정렬을 유지합니다.

## 5번
`golden-time-news.original.js`와 비교하면 실행 JS 변경은 아래 두 가지뿐입니다.
1. 계약 판정의 전체 건수에 `unresolved`를 포함: 사용자가 2번 기준으로 통합하도록 지시한 항목.
2. sparkSvg의 좌표계와 여백: 사용자가 요청한 그래프 끝 점 잘림 수정.

효과음의 음색·파형·타이밍과 뉴스·지진 연출은 원본을 유지합니다. Safari 재생 재개 보완은 아래 최신 변경에 명시합니다. 임의의 Safari/HTMLAudio/WAV 경로와 추가 테스트 화면을 제거했습니다. CSS는 원본 뒤에 요청된 뉴스 이전/다음 버튼 중앙 정렬과 시황 그래프 여백만 추가합니다.

## 6번
사용자가 지시한 2번의 정답 +100, 일반 오답 -40, 부실 승인 -100, 미처리 -60을 전체 건수로 나누는 기준과 unresolved 집계를 지원하도록 확장했습니다. 일자, 예산 단위, 정산, 다음 날 효과, 저장, 랭킹은 6번의 공통 세션을 사용합니다.

## 메인 UI
사용자가 요청한 여성 주무관 고정, 이름 입력, 판정 결과의 일반 안내, 체크 표시 정렬, 새 게임 초기화, 뉴스·업무 화면 배치 수정을 유지합니다. 게임 상태의 원본은 6번 세션 하나입니다.

## 확인 범위
원본 코드 비교와 DOM 기반 5일 진행·재시작 검사는 수행했습니다. 실제 Mac Safari 음향 출력은 검증하지 못했으므로 원본 복원과 소리 문제 해결을 구분합니다.

메인 이름 입력 확인은 실제 버튼 클릭/Enter 키 이벤트에서 바로 뉴스를 호출합니다. 별도 오디오 파일이나 다른 재생 엔진을 추가하지 않습니다.

## 원본 음향 비교 후 메인 연결 보완
5번 원본 데모에서 실제 소리가 난다는 사용자 확인을 받았습니다. 메인 접속 자동 뉴스만 클릭 후 실행으로 바꾸고, 이전에 저장된 음소거 값은 한 번 해제합니다. 이 처리는 5번의 기존 setMuted API를 사용하며 5번·2번·6번 파일은 변경하지 않습니다.

저녁 뉴스 종료 후 다음 날 출근 대기 화면을 표시합니다. `n일차 출근하기`를 눌러야 5번 모듈의 아침 뉴스를 시작하며, 새로고침해도 출근 대기를 복원합니다. 5일차는 출근 대기 없이 최종 결과로 이동합니다. 이번 변경은 메인 연동과 화면 스타일에만 적용했으며 2·5·6번 모듈 및 효과음 코드는 변경하지 않았습니다.

저녁 뉴스의 원본 닫기 페이드 뒤에 출근 화면을 미리 배치해 업무 화면이 잠깐 드러나는 전환을 방지합니다. 뉴스 종료 전에는 출근 화면을 조작할 수 없습니다.

## 최신: 원본 데모의 무대 전환 및 Safari 재개
- 뉴스와 출근 화면을 같은 `#news-stage` 컨테이너에 유지합니다. 별도 dialog를 열고 닫는 방식을 제거했습니다. 낮 업무 종료 → 퇴근 확인 → 저녁 뉴스 → 출근하기 → 아침 뉴스 → 업무 순서입니다.
- 업무 종료 버튼은 업무 카드 바로 위에 배치하고 최소 높이 60px, 글자 20px로 표시합니다.
- 5번 Sound의 원래 오디오 컨텍스트가 `suspended`뿐 아니라 Safari의 `interrupted`일 때도 resume합니다. resume 실패는 Promise 거부를 처리합니다.
- 기존 컨텍스트를 재개하는 `resumeSound()`를 버튼 클릭에서 호출하고, 음소거를 해제할 때도 즉시 재개합니다. 효과음 합성식과 뉴스 판정은 변경하지 않습니다.
- 실제 Mac Safari 스피커 출력은 이 환경에서 직접 확인할 수 없습니다. 모사 컨텍스트로 클릭 내 생성, interrupted/suspended 복구, 원본 효과음 호출을 검증합니다.

업무 종료 버튼은 아침 뉴스 미리보기와 같은 컨테이너의 바로 아래에 배치합니다. 출근 대기는 자동으로 버튼에 포커스하지 않으며, 새 포인터/키 입력으로 명시적으로 출근 버튼을 눌러야 아침 뉴스가 열립니다. 연속 클릭, Enter 반복 및 다른 아침 뉴스 진입으로 출근 대기를 건너뛰지 않습니다. 효과음 코드는 이번 수정에서 변경하지 않았습니다.

아침 뉴스 재생 중에는 출근 대기 배경을 숨기고 업무 화면을 뒤에 준비합니다. 원본 뉴스 닫기 페이드가 업무 화면으로 바로 이어지며 효과음 및 업무 종료 버튼 배치는 변경하지 않습니다.

## 5번 전달 이미지 연결 완료
`assets/news/`에 ZIP에서 받은 원본 16장을 그대로 보관합니다. 달이 4개 표정(happy/calm/worry/sad), 시민 3명 × 3개 표정(happy/worry/upset), 배경 3장(disaster/warehouse/office)을 연결했습니다. 시민의 joy·relief는 happy, angry·upset은 upset에 연결하며, 지진·교량 기사는 같은 disaster 사진을 사용합니다. 5번 데모의 assets 구성과 같습니다.
이미지는 integration.js의 newsAssets 한 곳에서 설정하고 새 게임에서도 재사용합니다. 뉴스·효과음·점수·화면 전환 코드는 이번 변경에서 수정하지 않았습니다. 전체 코드 ZIP과 단일 HTML에도 포함합니다. 원본 비교 데모의 img 폴더도 함께 채웠습니다.

## Safari 음향 재연결
원본 tone/rumble 및 효과음별 주파수·음량·타이밍은 유지합니다. 닫힌 컨텍스트를 다시 만들고, suspended/interrupted의 resume 완료 후에 효과음을 예약합니다. 뉴스 상단의 ‘소리 다시 연결’은 기존 연결을 닫고 사용자 클릭 안에서 새 연결을 만들어 원본 확인음을 재생합니다. 연결 실패는 화면에 표시하며, 연결 성공은 실제 스피커 출력을 보증하는 의미가 아닙니다. 이미지·점수·진행·업무 종료 버튼 위치는 유지합니다.

Safari에서는 modules/golden-time-audio.js가 실제 WAV 음원 파일을 HTMLAudio로 재생합니다. WAV 7개는 5번의 음정·음량·타이밍을 바탕으로 만들었으며 지진 진동음은 원본과 마찬가지로 무작위 잡음입니다. 뉴스에서 효과음을 호출하는 시점과 원본 WebAudio 합성 정의는 유지합니다. 뉴스 상단 재연결 버튼에는 실제 음원 재생 컨트롤이 표시되고, 재생 거부 오류를 보여줍니다. 연결 상태만으로 소리가 들린다고 표시하지 않습니다. 이미지·점수·게임 진행은 유지합니다.

뉴스 다음 버튼은 기존 입체 하단과 한글 글꼴의 시각적 중심을 고려해 글자·화살표를 아래로 0.18em 보정했습니다. 가로 중앙 정렬, 효과음·진행 로직은 유지하며 CSS만 조정합니다.
